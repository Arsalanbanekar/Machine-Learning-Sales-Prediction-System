# 📈 Machine Learning Sales Prediction System

A simple machine learning web application built with **Python, Scikit-learn, and Streamlit** that predicts product sales based on advertising spend across TV, Radio, and Newspaper channels.

🔗 **Live App:** https://sales-predictor-ltx9kpf2ucgzbrwnlzmczo.streamlit.app/

---

## 🚀 Features
- Predicts sales using a trained **Linear Regression model**
- Interactive UI built with **Streamlit**
- Real-time predictions based on user input
- Deployed on **Streamlit Cloud**
- Clean, minimal dependency setup

---

## 🧠 Machine Learning Model
- Algorithm: **Linear Regression**
- Libraries: `scikit-learn`, `numpy`, `pandas`
- Inputs:
  - TV Advertising Spend
  - Radio Advertising Spend
  - Newspaper Advertising Spend
- Output:
  - Predicted Sales

---

## 🛠 Tech Stack
- **Programming Language:** Python
- **ML Library:** Scikit-learn
- **Frontend / UI:** Streamlit
- **Deployment:** Streamlit Cloud
- **Version Control:** Git & GitHub
